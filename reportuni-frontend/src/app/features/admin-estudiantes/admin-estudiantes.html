Estudiantes

Carga masiva de cuentas desde un archivo CSV. Cada estudiante recibe como contraseña inicial su número de documento, y después puede cambiarla desde su perfil.

Formato del archivo

La primera fila debe tener los encabezados documento, nombre y correo, separados por punto y coma o por coma. Máximo 1000 estudiantes y 2 MB por carga.

  • Si el correo ya existe, se actualiza el nombre y no se toca la contraseña.
  • Las filas con errores se rechazan y las demás se cargan.
  • El archivo no se guarda en el servidor.
